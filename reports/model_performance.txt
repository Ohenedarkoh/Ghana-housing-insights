## 1. Introduction & Objective

This report details the development, optimization, and performance of an XGBoost regression model designed to predict housing prices based on various property features. The primary objective is to accurately estimate housing prices to provide actionable insights for real estate valuation and investment strategies.

---

## 2. Data Overview

The model was trained on a cleaned dataset derived from scraped property listings from Meqasa. The data underwent the following key processing steps:
*   **Source**: Meqasa property listings.
*   **Cleaning**: Handling missing values, converting data types, and removing irrelevant columns.
*   **Feature Engineering**: Creation of grouped amenity features (e.g., `comfortFeatures`, `luxuryFeatures`, `exSpace`) from individual amenity flags.
*   **Target Transformation**: Log transformation applied to the `Price` column (`LogPrice`) to address skewness and improve model linearity assumptions.

**Key Features Used:**
*   `Bedrooms`
*   `Bathrooms`
*   `luxuryFeatures`
*   `comfortFeatures`
*   `utilityFeatures`
*   `connectivityFeatures`
*   `exSpace`
